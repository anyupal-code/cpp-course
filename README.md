# Курс по C++: от основ до параллельных вычислений

Добро пожаловать в репозиторий с материалами учебного курса по языку программирования C++.

## О курсе

Этот курс представляет собой последовательное погружение в язык C++ — от самых азов до продвинутых тем, включая многопоточность, работу с графическими картами и компьютерное зрение. Материал построен так, чтобы студент не только изучил синтаксис, но и понял внутреннее устройство памяти, принципы эффективного программирования и современные подходы к разработке.

**Цель курса:** сформировать прочную базу для написания высокопроизводительных приложений и подготовки к работе с большими проектами.

## Как пользоваться этим репозиторием

1. **Порядок изучения:** следуйте нумерации папок (или тем) в списке выше.
2. **Код:** каждый блок сопровождается примерами кода и практическими заданиями.
3. **Запуск:** большинство программ компилируется стандартным компилятором (g++/clang). При необходимости в папке с темой есть `CMakeLists.txt` или инструкция по сборке.

## Требования к ПО

- Компилятор с поддержкой C++17 (или новее) — например, `g++ 7+`, `clang 10+`, или Microsoft Visual Studio 2019+
- Для тем 23–27:
  - Система сборки CMake (рекомендуется)
  - Для OpenCL: драйверы и SDK от производителя GPU (NVIDIA/AMD/Intel)
  - Для OpenCV: установленная библиотека OpenCV (версия 4.x)
